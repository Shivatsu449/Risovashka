# Luma Paint

Небольшой графический редактор для Windows на Python и PyQt6. Работает локально: без аккаунта, сервера, Docker и подключения к интернету при рисовании.

## Возможности

- Кисть и ластик с толщиной от 1 до 80 пикселей, в том числе рисование одиночным щелчком.
- Линия, прямоугольник и эллипс; предварительный просмотр фигуры и необязательная заливка фигур.
- Пипетка, палитра из 18 цветов и выбор произвольного цвета.
- Открытие PNG, JPEG, BMP и WebP; сохранение в PNG, JPEG и BMP.
- Новый холст, изменение размера изображения, поворот и отражение.
- Масштаб 10–400%, прокрутка и вписывание холста без изменения самого рисунка.
- Отмена и повтор действий, ограничение памяти истории.
- Подтверждение перед закрытием или заменой несохранённого рисунка.
- Проверка ошибок записи и сохранение через временный файл с заменой после успешной записи.

## Запуск готового EXE

Скачайте `LumaPaint.exe` из приложенных файлов или раздела **Releases** репозитория и откройте двойным щелчком. Python и дополнительные пакеты для готовой сборки не требуются. Установка не нужна.

Сборка предназначена для **Windows x64** и проверена на Windows 11. Запуск на Windows 10 отдельно не проверялся. Другие операционные системы требуют отдельной сборки из исходников. Первый запуск одиночного EXE может занимать несколько секунд: он распаковывает встроенные библиотеки во временную папку.

EXE не подписан коммерческим сертификатом. Не отключайте средства защиты Windows ради запуска программы.

## Запуск из исходников

Нужен **Python 3.12 x64**; именно на этой версии проверялся проект. Откройте терминал в папке с `main.py`:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

После установки зависимостей можно использовать `start.bat`. Он запускает существующее окружение `.venv`, ничего не скачивая автоматически.

Изображение также можно передать при запуске:

```powershell
.venv\Scripts\python.exe main.py "C:\Pictures\рисунок.png"
```

## Управление

| Действие | Клавиши |
| --- | --- |
| Кисть / ластик | B / E |
| Линия / прямоугольник / эллипс | L / R / O |
| Пипетка | I |
| Новый рисунок / открыть | Ctrl+N / Ctrl+O |
| Сохранить / сохранить как | Ctrl+S / Ctrl+Shift+S |
| Отменить | Ctrl+Z |
| Повторить | Ctrl+Y или Ctrl+Shift+Z |
| Вписать холст / масштаб 100% | Ctrl+0 / Ctrl+1 |
| Масштаб | Ctrl+колесо над холстом, список на панели или меню «Вид» |
| Отменить незавершённую фигуру или штрих | Esc, пока курсор работает на холсте |
| Очистить холст | Ctrl+Delete, с подтверждением |

Для свободного рисования удерживайте левую кнопку мыши. Для фигур нажмите в начальной точке, потяните мышь и отпустите в конечной. Один штрих или одна фигура — одно действие в истории. Выбор цвета после ластика или пипетки возвращает кисть.

## Особенности работы с файлами

- Холст непрозрачный и белый. Прозрачные области открытого PNG/WebP заменяются белым; ластик также рисует белым. Слои и прозрачный экспорт не предусмотрены.
- PNG лучше подходит для сохранения рисунков без потери качества. JPEG использует сжатие с потерями.
- Формат сохранения определяется расширением файла. Используйте `.png`, `.jpg`, `.jpeg` или `.bmp`.
- WebP открывается для редактирования, но сохраняется через «Сохранить как» в поддерживаемом формате.
- История хранится только в текущем сеансе. Предел — 30 шагов и 128 МиБ снимков; на больших изображениях доступно меньше шагов.
- Максимум — 16 миллионов пикселей и 8192 пикселя по каждой стороне. Это ограничивает расход памяти.
- При создании нового документа или открытии другого файла история предыдущего документа сбрасывается после подтверждения сохранения/отмены.
- Автосохранение не предусмотрено. Регулярно сохраняйте работу через Ctrl+S.

## Проверки

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют координаты при масштабе, одиночную точку, фигуры, ластик, пипетку, историю, отмену сохранения/открытия, обработку ошибок и запись в файлы с кириллическими именами. Подробности и ограничения проверки — в [docs/TESTING.md](docs/TESTING.md).

## Самостоятельная сборка EXE

Собирать Windows EXE нужно на Windows:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe build_exe.py
```

Результат — `dist/LumaPaint.exe`. Для диагностической версии в папке:

```powershell
.venv\Scripts\python.exe build_exe.py --onedir --console
```

Сценарий создаёт иконку, собирает сведения о лицензиях зависимостей и изолирует поиск библиотек от посторонних программ в PATH. Готовые файлы из `dist/` публикуйте в **GitHub Releases**, а не в истории исходников. До создания релиза EXE остаётся отдельным приложенным файлом.

```text
├── requirements.txt
├── requirements-build.txt
├── start.bat
└── docs/TESTING.md
```
