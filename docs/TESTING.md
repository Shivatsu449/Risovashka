# Проверки Luma Paint

## Автоматические проверки

21 регрессионная проверка выполнена успешно на Windows x64, Python 3.12.14 и PyQt6 6.12.0:

- одиночный щелчок оставляет точку;
- штрих при масштабе 200% попадает в правильные пиксели;
- один жест создаёт один шаг истории;
- линия, прямоугольник и эллипс фиксируются корректно;
- предварительный просмотр фигуры не изменяет документ, Esc отменяет фигуру;
- ластик и пипетка работают, пипетка не меняет документ;
- отмена, повтор и возврат к сохранённой версии корректно меняют признак несохранённой работы;
- новый штрих после отмены сбрасывает повтор;
- пустое действие не создаёт историю и не сбрасывает повтор;
- история укладывается в заданный бюджет памяти;
- неподдерживаемые размеры и повреждённые изображения отклоняются;
- PNG, JPG и BMP записываются и читаются, включая пути с кириллицей;
- прозрачный импорт преобразуется в белую непрозрачную основу;
- при принудительной ошибке записи исходный файл остаётся нетронутым, документ — несохранённым;
- отмена закрытия, сохранения и открытия не приводит к потере текущего рисунка;
- поворот и отражение отменяются;
- выбор цвета после ластика синхронизирует инструмент и кнопку кисти.

## Проверки сборки

Проверены сборка в папке и одиночный Windows EXE. При первоначальной проверке найдена и исправлена проблема поиска DLL: сценарий сборки теперь исключает влияние PATH других программ.

Диагностическая сборка открылась в обычном окне Windows; в ней через интерфейс выполнены рисование и отмена штриха. Окончательный одиночный EXE также открыт из отдельной папки готовых файлов: окно редактора отобразилось, на холсте выполнено рисование. Рядом с EXE не требовались исходники или папка Python. Полный цикл сохранения через диалоги финального EXE отдельно не выполнялся: файловые операции проверены автоматическими тестами исходников.

## Границы

Это проверка на конкретной машине Windows 11 x64. Чистая виртуальная машина, Windows 10, macOS и Linux отдельно не проверялись. Поведение при отключении питания, исчерпании памяти и всех возможных повреждениях файлов не гарантируется. Версия не содержит слоёв, прозрачного холста, выделения, текстового инструмента и автосохранения.

Журнал необработанных ошибок, если удалось создать, хранится в локальной папке данных приложения `LumaPaint/Luma Paint` в профиле пользователя. Изображения и журнал не отправляются по сети.
